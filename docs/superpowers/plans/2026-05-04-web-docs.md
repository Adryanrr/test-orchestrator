# Web Documentation Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a FastAPI + WebSocket documentation site that explica o projeto, mostra código com syntax highlight, e executa os testes em tempo real via terminal no browser.

**Architecture:** FastAPI serve um único `index.html` com 7 seções de conteúdo. Um endpoint WebSocket executa `pytest` via `asyncio.create_subprocess_exec` e transmite cada linha do stdout ao cliente em tempo real, terminando com uma mensagem `__RESULT__:status:passed:failed:errors`. Frontend em vanilla JS (~150 linhas) sem build step.

**Tech Stack:** Python 3.12, FastAPI, uvicorn, asyncio subprocess, Vanilla JS, CSS Custom Properties, Prism.js (CDN)

                msg = ws.receive_text()
                messages.append(msg)
                if msg.startswith("__RESULT__:"):

    parts = result_msgs[0].split(":")
    assert len(parts) == 5

    assert parts[1] == "passed"
    assert int(parts[2]) >= 1

```python
@app.websocket("/ws/run-tests")
async def run_tests(websocket: WebSocket):
    await websocket.accept()

    env = {**os.environ, "PYTHONPATH": str(PROJECT_ROOT)}
    process = await asyncio.create_subprocess_exec(
        *PYTEST_COMMAND,
        stdout=asyncio.subprocess.PIPE,
        stderr=asyncio.subprocess.STDOUT,
        cwd=PYTEST_CWD,
        env=env,
    )

    passed = failed = errors = 0
    async for raw in process.stdout:
        line = raw.decode("utf-8", errors="replace").rstrip()
        await websocket.send_text(line)
        if " PASSED" in line:
            passed += 1
        elif " FAILED" in line:
            failed += 1
        elif " ERROR" in line:
            errors += 1

    await process.wait()
    status = "passed" if process.returncode == 0 else "failed"
    await websocket.send_text(f"__RESULT__:{status}:{passed}:{failed}:{errors}")
    await websocket.close()
```

      <p>Problemas reais encontrados durante o desenvolvimento, com a causa raiz e a solução implementada.</p>

      <div class="timeline">

        <div class="timeline-item">
          <h4>Inputs React ignorados no headless Chrome</h4>
          <div class="meta">Commit: fix/usar-javascript-nativo-para-preencher-inputs-react-no-checkout</div>
          <p>O SauceDemo usa React com inputs controlados. No Chrome headless do Linux (GitHub Actions), o Selenium nativo (<code>send_keys</code>) não disparava os eventos <code>input</code>/<code>change</code> que o React espera — os campos apareciam preenchidos visualmente mas o React não reconhecia o valor.</p>
          <pre><code class="language-python">JS_SET_INPUT = """
var nativeSetter = Object.getOwnPropertyDescriptor(
    window.HTMLInputElement.prototype, 'value').set;
nativeSetter.call(arguments[0], arguments[1]);
arguments[0].dispatchEvent(new Event('input', { bubbles: true }));
arguments[0].dispatchEvent(new Event('change', { bubbles: true }));
"""

def _js_fill(self, element, value: str):
    self.driver.execute_script(JS_SET_INPUT, element, value)</code></pre>
        </div>

        <div class="timeline-item">
          <h4>Botão Finish sem efeito com ActionChains</h4>
          <div class="meta">Commit: fix/reverter-actionchains-no-botão-finish-para-manter-clique-nativo</div>
          <p>O <code>ActionChains.click()</code> simula eventos de mouse sintetizados que o React ignora em modo headless. A solução foi usar <code>execute_script</code> para disparar o click diretamente via JavaScript nativo, que o React processa corretamente.</p>
          <pre><code class="language-python"># Antes (não funcionava headless):
ActionChains(self.driver).move_to_element(btn).click().perform()

# Depois (funciona headless + Linux CI):
self.driver.execute_script("arguments[0].click()", btn)</code></pre>
        </div>

        <div class="timeline-item">
          <h4>Race condition no auto-merge do CI</h4>
          <div class="meta">Commit: ci/unificar-workflows-em-um-pipeline-único-para-corrigir-race-condition-do-auto-merge</div>
          <p>Dois workflows paralelos (<code>api-tests.yml</code> e <code>web-tests.yml</code>) tentavam criar e mergear o mesmo PR simultaneamente, causando erros de conflito. A solução foi unificar em um único <code>ci.yml</code> com <code>concurrency: group: ci-${{ github.ref }}</code>.</p>
          <pre><code class="language-yaml">concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true

jobs:
  api-tests: ...
  web-tests: ...
  auto-merge-to-developer:
    needs: [api-tests, web-tests]</code></pre>
        </div>

        <div class="timeline-item">
          <h4>scrollIntoView quebrando interações no checkout</h4>
          <div class="meta">Commit: fix/remover-scrollIntoView-de-todas-as-page-objects-e-unificar-JS-click</div>
          <p>Chamadas de <code>scrollIntoView</code> antes de interagir com elementos criavam estado inconsistente nos inputs controlados pelo React — o scroll mudava o foco e invalidava o estado anterior. Removidas de todas as Page Objects; o scroll acontece implicitamente pelo driver quando necessário.</p>

// Theme toggle
const html = document.documentElement;
const themeToggle = document.getElementById('theme-toggle');
const stored = localStorage.getItem('theme') || 'dark';
html.setAttribute('data-theme', stored);
themeToggle.textContent = stored === 'dark' ? '☀️ Light' : '🌙 Dark';

themeToggle.addEventListener('click', () => {
  const current = html.getAttribute('data-theme');
  const next = current === 'dark' ? 'light' : 'dark';
  html.setAttribute('data-theme', next);
  localStorage.setItem('theme', next);
  themeToggle.textContent = next === 'dark' ? '☀️ Light' : '🌙 Dark';
});

// Hamburger (mobile)
const hamburger = document.getElementById('hamburger');
const sidebar = document.getElementById('sidebar');
hamburger.addEventListener('click', () => sidebar.classList.toggle('open'));
document.addEventListener('click', (e) => {
  if (!sidebar.contains(e.target) && !hamburger.contains(e.target)) {
    sidebar.classList.remove('open');
  }
});

// Scroll spy
const sections = document.querySelectorAll('.section');
const navLinks = document.querySelectorAll('.sidebar-nav a');

const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      navLinks.forEach(a => a.classList.remove('active'));
      const link = document.querySelector(`.sidebar-nav a[href="#${entry.target.id}"]`);
      if (link) link.classList.add('active');
    }
  });
}, { rootMargin: '-20% 0px -70% 0px' });

sections.forEach(s => observer.observe(s));

// Copy buttons
document.querySelectorAll('pre').forEach(pre => {
  const btn = document.createElement('button');
  btn.className = 'copy-btn';
  btn.textContent = 'Copiar';
  pre.appendChild(btn);
  btn.addEventListener('click', () => {
    const code = pre.querySelector('code');
    const text = code ? code.textContent : pre.textContent.replace('Copiar', '').trim();
    navigator.clipboard.writeText(text).then(() => {
      btn.textContent = 'Copiado!';
      setTimeout(() => { btn.textContent = 'Copiar'; }, 2000);
    });
  });
});

// WebSocket terminal
const runBtn = document.getElementById('run-btn');
const terminal = document.getElementById('terminal');
const resultBadge = document.getElementById('result-badge');

runBtn.addEventListener('click', () => {
  runBtn.disabled = true;
  runBtn.textContent = '⏳ Rodando...';
  terminal.innerHTML = '';
  terminal.classList.add('visible');
  resultBadge.className = 'result-badge';

  const ws = new WebSocket(`ws://${location.host}/ws/run-tests`);

  ws.onmessage = (event) => {
    const msg = event.data;

    if (msg.startsWith('__RESULT__:')) {
      const parts = msg.split(':');
      const status = parts[1];
      const passed = parts[2];
      const failed = parts[3];
      const errors = parts[4];

      resultBadge.classList.add('visible', status);
      resultBadge.textContent = status === 'passed'
        ? `✅ ${passed} passed`
        : `❌ ${failed} failed / ${errors} errors`;

      runBtn.disabled = false;
      runBtn.textContent = '▶ Rodar todos os testes';
      return;
    }

    const line = document.createElement('div');
    line.className = 'terminal-line';

    if (msg.includes(' PASSED'))      line.classList.add('passed');
    else if (msg.includes(' FAILED')) line.classList.add('failed');
    else if (msg.includes(' ERROR'))  line.classList.add('error');
    else                              line.classList.add('default');

    line.textContent = msg;
    terminal.appendChild(line);
    terminal.scrollTop = terminal.scrollHeight;
  };

  ws.onerror = () => {
    const line = document.createElement('div');
    line.className = 'terminal-line error';
    line.textContent = 'Erro: não foi possível conectar. Verifique se o servidor está rodando.';
    terminal.appendChild(line);
    runBtn.disabled = false;
    runBtn.textContent = '▶ Rodar todos os testes';
  };

  ws.onclose = () => {
    if (runBtn.disabled) {
      runBtn.disabled = false;
      runBtn.textContent = '▶ Rodar todos os testes';
    }
  };
});
